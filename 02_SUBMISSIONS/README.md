# Submissions

## Step 1 — Make your folder
Create a folder with your GitHub username:

`02_SUBMISSIONS/<your-github-username>/`

## Step 2 — Minimum required files
Inside your folder, include:
1. `README.md` (your writeup)
2. Evidence (screenshots / PDFs / exports)

## Suggested structure inside your folder
- `README.md`
- `images/` (screenshots)
- `exports/` (STEP/STL/etc.)
- `drawings/` (PDFs)

## File naming
Use clear names + versions.

Format:
`<UWID>_<Thing>_v<##>.<ext>`

Examples:
- `s3howe_BracketDrawing_v01.pdf`
- `s3howe_BracketModel_v01.step`
- `s3howe_ManufacturingNotes_v02.pdf`

## What not to do
- Don’t edit other people’s folders.
- Don’t upload raw CAD assemblies unless we explicitly ask for them.
