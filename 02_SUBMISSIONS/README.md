# Submissions

Create a folder with your GitHub username:

`02_SUBMISSIONS/<your-github-username>/`

Inside your folder, include at minimum:
1. `README.md` (short writeup)
2. Screenshots or PDFs that prove the work is complete

## File naming convention
Use:
`<UWID>_<Task>_v<##>.<ext>`

Examples:
- `s3howe_BracketDrawing_v01.pdf`
- `s3howe_ManufacturingPlan_v02.pdf`
- `s3howe_BracketModel_v01.step`

## What NOT to do
- Don’t edit other people’s folders.
- Don’t upload raw CAD assemblies unless explicitly requested.
